# Tile abstraction

A slide deck on FlyDSL layouts: reading a shape and stride, combining layout functions, and using them in a tiled copy and a tiled MMA.

Open the deck:

```
python3 serve_nocache.py
```

Then go to `http://<this machine>:8765/presentation/`.

Start at `presentation/index.html`. The slides in `presentation/` link to the pages in this folder.
