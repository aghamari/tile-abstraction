Why a layout

A GPU kernel gives each thread a piece of the tensor. The tensor is split into tiles, and each tile is split across the threads of the block. A layout is the map from a thread and a value to the element, and to the offset of that element.

  1. 1

    Read a layout

    A layout prints as shape and stride. Reading it means naming the coordinate that goes in and the offset that comes out.

  2. 2

    Combine layout functions

    raked_product, right_inverse, and composition take small layouts and return the one layout a tile needs. make_layout_tv is that combination.

    Use the layout in the kernel
